## Task Description

The goal of this query is to provide a comprehensive continental breakdown of business performance by combining revenue data with user registration and session activity.

The report answers two key business questions: how revenue is distributed across continents (including the split between mobile and desktop devices), and how engaged and verified the user base is in each region.

To achieve this, the query joins session, order, product, and account data from five tables. Revenue metrics are calculated by summing product prices per continent and splitting them by device type. User metrics are calculated by counting sessions, linked accounts, and accounts that have passed verification.

The final output ranks continents by their share of total global revenue, giving stakeholders a clear view of which regions drive the most value and where user acquisition and verification efforts stand.
